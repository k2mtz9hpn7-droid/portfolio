# 商家增长运营作品集

## 使用方法

1. 双击 `index.html` 即可预览。
2. 打开 `content.js`，替换姓名、指标、能力和四个案例。
3. 摄影作品已按合集放入 `images/`：`portrait/`（人物情绪）、`commerce/`（商业景物）、`street/`（城市与人）、`space/`（空间观察）。增删作品时把 jpg 放进对应文件夹，并同步更新 `content.js` 里 `photoCollections` 的文件列表。
4. 案例封面在 `images/` 根目录按 `case-01-cover.jpg` 至 `case-04-cover.jpg` 命名。
5. AI 漫剧视频放在 `videos/` 目录，替换/增删见下方「AI 漫剧视频」说明。
6. 没有图片时页面会使用彩色占位封面，不影响浏览。

## 填写原则

- 所有数据必须来自真实项目；敏感金额可用区间或百分比。
- 团队项目明确写出个人职责。
- 模拟项目必须保留“模拟项目”标识，不填写虚构结果。
- 每个案例优先补充：广告后台截图、素材对比、账户结构、数据趋势和复盘结论。
- `personalSkills` 用来填写你真实制作的个人 Skill，建议附上运行链接、截图或演示视频。
- 摄影作品尽量按系列选择，首版建议保留 5–8 张，不要混放大量零散照片。

## AI 漫剧视频

「AI漫剧」是首屏之后的第一个内容区块，展示位最显眼；「核心业绩」数据条紧跟在漫剧之后、项目案例之前，并与案例区块在视觉上连成一个整体（数据条无底边线、与案例之间间距收窄）：

- 视频文件放在 `videos/` 目录，当前为 `ai-drama-01.mp4`（主打）至 `ai-drama-03.mp4`。替换视频时保持文件名不变即可；增删或改名就同步修改 `content.js` 里的 `aiDrama` 数组。
- **第一条**会作为主打全宽展示，其余并排两列；手机端自动叠成一列。
- 视频进入视口自动静音播放、离开暂停；访客点击右下角「点击开声音」按钮后开启声音并显示原生控制条。
- `content.js` 里每支视频的 `title` / `note` 目前是占位文案，请按每支视频的实际内容改成准确的标题和说明。
- 系统开启「减少动态效果」时不自动播放，改为显示原生控制条由访客手动播放。

## 可复制的 Skill

「AI能力」板块默认只展示前 3 个主打 Skill，其余收进「效率工具箱」抽屉，点「展开其余 N 个效率工具」才会出现，手机端不会被九个卡片刷屏。每张卡片支持一键复制完整的 SKILL.md：

- Skill 正文统一维护在 `skills.js`，卡片上的「复制此 Skill」按钮会弹出预览与复制入口。
- 卡片与 Skill 的对应关系由 `content.js` 里 `personalSkills` 的 `skillId` 字段决定，需与 `skills.js` 中的 id 一致。
- `content.js` 里 `personalSkills` 的**前 3 条**会作为主打大卡，其余进入抽屉；想改主打数量，调 `app.js` 顶部的 `FEATURED_SKILL_COUNT`。
- 页面自带三步安装引导：复制内容 → 保存到 `~/.claude/skills/名称/SKILL.md` → 在 Claude Code 中直接调用；也支持整段粘贴给任意 AI 对话使用。
- 想新增 Skill：在 `skills.js` 加一个 id 与正文，在 `content.js` 的 `personalSkills` 增加一张卡片并填上相同的 `skillId` 即可。

## AI 数字分身对话框

页面右下角的「问问 AI 版的我」对话框由 `ai-chat.js` 驱动，访客可以通过提问快速了解你：

- 默认是**内置问答引擎**：回答内容自动读取 `content.js` 的最新数据，免费、离线、可安全公开发布，无需任何配置。
- 想接入真正的大模型对话：按《AI分身配置指南.md》在扣子（Coze）上搭建机器人（人设 Prompt 已写好，知识库直接粘贴《数字分身资料库.md》），然后把嵌入地址填入 `ai-chat.js` 顶部的 `AI_CHAT_CONFIG`。
- 「关于」板块的「或问问 AI 版的我」文字链接也会打开同一个对话框。
- 修改 `content.js` 数据后，记得同步更新《数字分身资料库.md》（扣子知识库用），两边数据保持一致。
